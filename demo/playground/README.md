# ▶ Try Pet Freedom live in your browser

One link boots a **real WordPress** in your browser — no install, no account, no server — preloaded with the
Pet Freedom legal-status resource so you can click through it exactly as a visitor would. It runs on
[WordPress Playground](https://wordpress.github.io/wordpress-playground/) (WordPress compiled to
WebAssembly), entirely client‑side.

### Launch it

**Curated showcase (fast, ~26 pages):**

<https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/blonderoofrat/pet-freedom/main/demo/playground/blueprint.json>

**Full dataset (every jurisdiction, ~110 pages — slower to build):**

<https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/blonderoofrat/pet-freedom/main/demo/playground/blueprint-full.json>

It takes a few seconds to download WordPress and import the content. You'll land on the **Roof Rat Laws**
hub; pick a country, drill into a state, and you'll see real status badges, confidence levels, agency
confirmations, advocacy toolkits, and links to the official sources — the same output the skill publishes to
a live site.

> This is a **demo of the output**, not legal advice. The live, maintained resource is at
> [blonderoofrat.com/roof-rat-laws](https://blonderoofrat.com/roof-rat-laws/).

## What's in here

| File | What it is |
|---|---|
| `blueprint.json` | Playground recipe for the curated showcase (sets permalinks, imports the WXR, lands on the hub). |
| `blueprint-full.json` | Same, for the full every‑jurisdiction dataset. |
| `pet-freedom-demo.xml` | WordPress eXtended RSS (WXR) export of the curated pages. |
| `pet-freedom-full.xml` | WXR export of all jurisdictions. |
| `demo.config.json` | A **real, filled‑in** `config.json` (the roof‑rat configuration) — a worked example to copy from. |

The pages are generated by reusing the skill's own `build.py` renderers, so the demo is byte‑for‑byte what
the skill would publish. Internal navigation is rewritten to **root‑relative** links so the whole hierarchy
is clickable inside the sandbox; official sources, official agency contacts, and the funnel/attribution
links stay absolute. No private data is included (the dataset is the published, scrubbed one).

## Regenerate it (for your own species)

The demo is produced offline — no WordPress, no network — by `skill/playground.py`:

```bash
# Roof-rat demo (curated + full):
python skill/playground.py --full

# Your own species: point it at your config + data, and host the output on any static host.
python skill/playground.py \
  --config config.json \
  --source data/jurisdictions \
  --funnel-base https://your-site.example \
  --raw-base https://raw.githubusercontent.com/<you>/<repo>/main/demo/playground/
```

Then commit the generated `*.xml` + `blueprint.json` next to this README and share the
`https://playground.wordpress.net/?blueprint-url=<raw url to your blueprint.json>` link.

### Notes & limits
- Playground is **ephemeral**: changes a visitor makes vanish on reload. That's intended for a demo.
- The legal pages are text‑only (callouts, badges, links), so there are **no images** to wrangle (the WXR
  importer's usual cross‑origin image fetch isn't a factor here).
- `login` is enabled, so curious visitors can also open **wp‑admin → Pet Freedom** and see the companion
  plugin's *Get Started* page. (The companion plugin is optional and isn't required to view the resource.)
