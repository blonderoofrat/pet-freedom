# Host recipes (community‑submittable)

Setting up authenticated email (so agency inquiries don't bounce) is the fiddliest part, and it's host‑specific.
This folder collects short, **sanitized** how‑tos for individual hosts — use placeholders only, never real
domains/credentials.

See [`../EMAIL-DELIVERABILITY.md`](../EMAIL-DELIVERABILITY.md) for the host‑agnostic explanation (SPF + DKIM + DMARC)
and a worked SiteGround + Cloudflare example.

**Have a recipe for your host?** (Google Workspace, Fastmail, Zoho, Namecheap, Bluehost, a self‑hosted mail server…)
Please open a PR adding `recipes/<your-host>.md` with the steps — no secrets, just the clicks and the record shapes.
You'll help every keeper who comes after you.
